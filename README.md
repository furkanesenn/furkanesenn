## GitHub, 2021–2026

![GitHub contributions, authored commits, current project lines of code, and language mix](stats/profile-stats.svg)

The chart covers my GitHub activity since this account was created in 2021 and the current code in accessible projects. It includes aggregate data from private organization repositories without revealing their names or code. The snapshot was calculated on **24 September 2026**; [the aggregate data](stats.json) and [method](scripts/update_stats.py) are available here.

**What the numbers mean:** Contributions come from GitHub's yearly calendars. Authored commits are unique commits returned by GitHub search for my account. Current project LOC is the sum of non-blank, non-comment code lines at the latest default-branch revision of repositories I own or have committed to. Forks, dependency folders, build output, and documentation/configuration files are excluded. The LOC total includes teammates' code in those projects; it is a project-size measure, not a personal authorship claim.
