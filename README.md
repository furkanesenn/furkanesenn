## GitHub, 2021–2026

![Rounded lifetime GitHub contributions, authored commits, accessible project lines of code, and language mix](stats/profile-stats.svg)

The chart covers my GitHub activity since this account was created in 2021 and the current code in accessible projects. It includes aggregate data from private organization repositories without revealing their names or code. The snapshot was calculated on **24 September 2026**; [the aggregate data](stats.json) and [method](scripts/update_stats.py) are available here.

**What the numbers mean:** The contribution card rounds GitHub's yearly-calendar total to the nearest thousand; the exact snapshot is in the aggregate data. Authored commits are unique commits returned by GitHub search for my account. Project LOC sums non-blank, non-comment code lines at the latest default-branch revision of non-fork repositories this account can access, including organization and collaborator repositories. Dependency folders, build output, and common documentation/configuration files are excluded. The LOC total includes teammates' code and is a project-size measure, not a personal authorship claim. Deleted or inaccessible repositories cannot be counted.
